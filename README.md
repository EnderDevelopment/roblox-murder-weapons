# Roblox Murder vs Sheriff Weapon Spawner

This project contains scripts for a Roblox Murder vs Sheriff game that allows spawning weapons visible to all players. The scripts are written in Lua and are designed to be placed in the ServerScriptService in Roblox Studio. The main feature of this project is the ability to spawn weapons that are visible to all players and can be interacted with using click detectors.

## Install

1. Open Roblox Studio and create a new game or open an existing one.
2. Place the `WeaponSpawner.server.lua` script in the ServerScriptService.

## Use

1. Customize the weapon properties and positions as needed in the `WeaponSpawner.server.lua` script.
2. Replace the placeholder mesh and texture IDs with actual asset IDs from Roblox.
3. Test the game to ensure weapons spawn correctly and are visible to all players.
